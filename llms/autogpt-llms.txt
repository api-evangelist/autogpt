# AutoGPT

> AutoGPT is an open-source platform for building, deploying, and running AI agents that automate digital workflows — research, outreach, content, support — without writing code. Describe an outcome in plain language or assemble agents in a visual builder, then let them run continuously on schedules and triggers. Self-host the platform for free, or use the managed cloud at https://agpt.co.
